# Nutikate tehnoloogiate õpikeskkond

Õpikeskkond droonide, robootika ja nutikate tehnoloogiate õppemoodulite koostamiseks.

- **Veebileht:** [Ava droonirajaplaneerija]([https://karlhkhk.github.io/Nutikate-tehnoloogiate-opikeskkond/rajaplaneerija/](https://karlhkhk.github.io/Nutikate-tehnoloogiate-opikeskkond/rajaplaneerija/))
- **Minu GitHubi repositooriumid:** [github.com/Karlhkhk](https://github.com/Karlhkhk?tab=repositories)
- **Droonirajaplaneerija:** rajade koostamine, kontrollimine, eksport ja FPV-simulaator.
- **Keeled:** eesti, inglise ja soome keel.
